## How To Install APPs
- yang pertama install terlebih dahulu nodejs nya du link : https://nodejs.org/en
- lalu setelah sudah bisa langsung download di github 
- setelah sudah mengetikan 'npm install' untuk menginstall semuah dependencies
- lalu setelah sudah mengetikan 'npm run dev' untuk menjalankan aplikasi
- langkah terakhir kalian bisa bantu juga untuk kontribusi terkait pembuatan aplikasi tersebut dengan cara star terlebih dahulu projectnya
- lalu pull request dan bisa mengajukan kontribusi juga untuk pengembangan lainya terimakasih
